第 2 章：ML 專案流程與資料處理

本章涵蓋機器學習專案從問題定義到資料處理的完整流程，這是模型成敗的基礎。

問題定義

  • 分類 (Classification)：預測離散類別（如：垃圾郵件/正常郵件）。
  • 迴歸 (Regression)：預測連續數值（如：房價、溫度）。
  • 排名 (Ranking)：預測項目的排序（如：搜尋引擎結果、推薦系統）。
  • 多標籤 (Multi-label)：一個樣本可能同時屬於多個類別（如：電影同時是「動作」與「科幻」）。

資料切分與驗證策略

切分策略

  • Train / Validation / Test：
    • Train：模型學習參數。
    • Validation：調整超參數 (Hyperparameters)、Early Stopping。
    • Test：最終評估模型效能，不可用於訓練或調參。

交叉驗證 (Cross-Validation)

  • k-fold CV：將資料分成 k 等份，輪流當作驗證集。適用於資料量較少時。
  • 時間序列切分 (Time Series Split)：
    • 不可隨機打亂！必須依時間順序切分（如：用 1-3 月預測 4 月，用 1-4 月預測 5 月）。
    • 避免資料洩漏 (Data Leakage)（拿未來的資料預測過去）。

資料清理與異常值

  • 缺失值處理 (Missing Values)：
    • 刪除：若缺失比例極低。
    • 填補 (Imputation)：平均值、中位數、眾數、KNN 填補、模型預測填補。
  • 異常值處理 (Outliers)：
    • 識別：Box plot (IQR 法則)、Z-score (> 3)。
    • 處理：刪除、Winsorization (蓋帽法，將極端值限制在特定百分位數)。

特徵前處理

Feature Scaling

距離式模型 (KNN, SVM, K-Means) 對特徵尺度非常敏感。 * Standardization (Z-score)：\(\frac{x - \mu}{\sigma}\)。轉為平均 0，標準差 1。 * Min-Max Normalization：\(\frac{x - min}{max - min}\)。壓縮到 [0, 1]。

類別特徵編碼

  • One-hot Encoding：無序類別（如：顏色）。會造成維度災難。
  • Label Encoding：有序類別（如：尺寸 S/M/L）。
  • Target Encoding：用目標變數的平均值來編碼類別。需注意資料洩漏，應在 K-Fold 內進行。

不平衡資料處理

當某類別樣本數遠少於其他類別（如：詐欺偵測）。 * 權重調整 (Class Weights)：在 Loss Function 中加大少數類別的懲罰權重。 * 重新取樣 (Resampling)： * Oversampling：SMOTE (合成少數類別樣本)。 * Undersampling：隨機減少多數類別樣本。 * 閾值調整 (Threshold Moving)：調整分類閾值（預設 0.5），以平衡 Precision 與 Recall。

特徵工程實務

  • 交互特徵 (Interaction Features)：特徵相乘 (e.g., \(x_1 \times x_2\))，捕捉非線性關係。
  • 分箱 (Binning)：將連續變數轉為離散區間（如：年齡 -> 年齡層），增加魯棒性。
  • 時間窗與統計聚合：
    • 針對時間序列或 Log 資料。
    • Rolling Window：過去 7 天的平均消費、最大金額、次數。
  • 半結構化資料處理：
    • JSON Log 展開：將巢狀 JSON 欄位攤平為多個欄位。
    • 聚合 (Aggregation)：將多筆 Log 聚合為一筆使用者特徵（如：點擊次數、瀏覽類別分佈）。
