第 1 章：機器學習數學基礎補強

本章聚焦於支撐機器學習演算法的核心數學觀念，特別針對中級考試中常見的線性代數、機率統計與數值計算進行補強。

線性代數 for ML

向量與矩陣運算

  • 向量 (Vector)：資料的特徵表示。
    • 點積 (Dot Product)：\(\mathbf{a} \cdot \mathbf{b} = \sum a_i b_i = |\mathbf{a}| |\mathbf{b}| \cos \theta\)。幾何意義為投影與相似度計算。
  • 矩陣 (Matrix)：資料集或線性變換的表示。
    • 矩陣乘法直覺：將右邊矩陣的行 (Column) 進行左邊矩陣列 (Row) 的加權組合。
    • 轉置 (Transpose)：\(A^T\)，行列互換。
  • 逆矩陣 (Inverse Matrix)：\(A^{-1}\)，滿足 \(AA^{-1} = I\)。存在條件為行列式不為 0 (非奇異矩陣)。

特徵值與特徵向量

  • 定義：\(Av = \lambda v\)。矩陣 \(A\) 作用在向量 \(v\) 上，僅改變其長度 (\(\lambda\)) 而不改變方向。
  • 應用：
    • PCA：共變異數矩陣的特徵向量即為主成分方向。
    • 穩定性：特徵值的大小決定了系統在迭代過程中的收斂或發散。

機率與統計 for ML

機率分佈

  • 常見分佈：Bernoulli (二元), Binomial (多次二元), Normal (高斯), Poisson (計數)。
  • 條件機率：\(P(A|B) = \frac{P(A \cap B)}{P(B)}\)。

貝氏定理與 Naive Bayes

  • 貝氏定理：\(P(H|D) = \frac{P(D|H)P(H)}{P(D)}\)。
    • Posterior \(\propto\) Likelihood \(\times\) Prior。
  • Naive Bayes 分類器：假設特徵間相互獨立，簡化計算。適用於文本分類（垃圾郵件）。

期望值、變異數、共變異數

  • 期望值 (Expectation)：\(E[X]\)，平均水準。
  • 變異數 (Variance)：\(Var(X) = E[(X-\mu)^2]\)，資料的分散程度。
  • 共變異數 (Covariance)：\(Cov(X, Y)\)，衡量兩個變數變化的相關性。
    • 相關係數 (Correlation)：標準化的共變異數，範圍 [-1, 1]。

損失函數與風險

常見損失函數

  • MSE (均方誤差)：\(\frac{1}{n}\sum(y-\hat{y})^2\)。對異常值敏感。
  • MAE (平均絕對誤差)：\(\frac{1}{n}\sum|y-\hat{y}|\)。對異常值較魯棒。
  • 交叉熵 (Cross-Entropy)：\(-\sum p(x) \log q(x)\)。分類問題的標準損失函數。

經典迴歸假設與殘差圖

  • 迴歸假設：線性性、獨立性、常態性、變異數同質性 (Homoscedasticity)。
  • 殘差圖解讀：
    • 理想：隨機分佈在 0 軸上下。
    • 異常值：遠離 0 軸的點。
    • 非線性：呈現曲線（如拋物線）。
    • 異質變異：呈現漏斗狀（隨預測值變大，發散程度變大）。

蒙地卡羅方法與隨機模擬

隨機抽樣與模擬

  • 蒙地卡羅 (Monte Carlo)：利用大量隨機抽樣來估計數值或機率。
    • 應用：計算 \(\pi\) 值、風險評估、強化學習中的價值估計。
  • 風險區間估計：透過模擬不同情境（如骰子點數、再生能源發電量波動），計算特定事件發生的機率分佈與信賴區間。
  • 條件機率模擬：在特定條件下（如「已知第一顆骰子是 6」）進行抽樣，驗證理論機率。
