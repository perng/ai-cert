第 11 章：MLOps 與 AI 平台建置

MLOps 是讓 AI 從實驗室走向生產線的關鍵，結合了機器學習、DevOps 與資料工程的最佳實踐。

ML Lifecycle 與 CI/CD/CT

傳統 DevOps 強調 CI/CD，而 MLOps 多了一個 CT (Continuous Training)。

  1. 持續整合 (CI)：自動化測試程式碼、驗證資料格式 (Data Validation)。
  2. 持續部署 (CD)：自動化將模型打包、部署到測試或生產環境。
  3. 持續訓練 (CT)：
    • 當監控系統發現模型效能下降，或有新資料進入時，自動觸發重新訓練流程。
    • 確保模型能適應環境變化。

資料與特徵管線

  • ETL (Extract, Transform, Load)：資料抽取與清洗。
  • Feature Store：解決 “Training-Serving Skew” 問題。
    • Offline Store：儲存歷史特徵，供訓練用 (高吞吐)。
    • Online Store：儲存最新特徵，供即時推論用 (低延遲，如 Redis)。

模型部署模式與架構

  • 微服務架構 (Microservices)：
    • 將 AI 模型封裝為獨立的 API 服務 (如 Flask/FastAPI)。
    • 優點：解耦、易於獨立擴充與維護。
  • 部署模式：
    • Batch Inference (批次)：排程執行 (T+1)，適合行銷名單、報表。
    • Online Inference (即時)：REST/gRPC API，適合推薦、風控。
    • Edge Deployment (邊緣)：模型在裝置端執行，需考慮算力限制。

容器與 Kubernetes

  • Docker：將模型、程式碼、依賴套件打包成 Image，確保 “Build Once, Run Anywhere”。
  • Kubernetes (K8s)：
    • Auto-scaling：根據 CPU/GPU 使用率或流量自動增減 Pod。
    • Load Balancing：自動分配流量，確保高可用性 (HA)。
    • Rolling Update：零停機更新服務。

模型監控 (Model Monitoring)

模型上線後，環境與資料分佈可能會隨時間改變，導致模型失效。

  • 資料漂移 (Data Drift)：
    • 輸入資料的分佈發生變化 (如：使用者年齡層改變)。
    • \(P_{train}(X) \neq P_{serve}(X)\)
  • 模型漂移 (Model Drift / Concept Drift)：
    • 輸入與輸出的關係發生變化 (如：通膨導致同樣金額的購買力下降)。
    • \(P_{train}(Y|X) \neq P_{serve}(Y|X)\)
  • 監控指標：預測分佈、特徵統計量 (Mean/Std)、API 延遲、錯誤率。

模型壓縮與加速 (Model Compression)

為了在邊緣裝置或對延遲敏感的場景下運行，需對模型進行瘦身。

  • 知識蒸餾 (Knowledge Distillation)：
    • 訓練一個大模型 (Teacher) 教導一個小模型 (Student)。
    • Student 學習模仿 Teacher 的輸出機率 (Soft Targets)，保留大部分效能但體積大幅縮小。
  • 剪枝 (Pruning)：
    • 移除神經網路中不重要的權重 (接近 0 的連接) 或神經元。
    • 可大幅減少參數量與運算量，需配合硬體加速。
  • 量化 (Quantization)：
    • 將權重從 32-bit 浮點數 (FP32) 轉換為 8-bit 整數 (INT8) 甚至更低。
    • 模型大小減少 4 倍，推論速度加快，但精確度可能微幅下降 (需進行 Quantization-aware Training 或 Post-training Quantization)。

版本管理與部署策略

  • Model Registry：集中管理模型的版本 (v1.0, v1.1)、標籤 (Staging, Production) 與元數據 (Metrics)。
  • A/B Testing：流量分流 (50/50)，比較新舊模型在真實環境的商業指標 (如 CTR)。
  • Canary Deployment (金絲雀部署)：先將少量流量 (如 5%) 導向新模型，確認無誤後再逐步全量。
  • Shadow Deployment：新模型與舊模型同時跑 (新模型不回傳結果給用戶)，僅用於驗證效能與穩定性。
