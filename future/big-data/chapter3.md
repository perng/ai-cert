# 第 3 章：特徵工程

特徵工程 (Feature Engineering) 是將原始數據轉換為更能代表潛在問題特徵的過程，以提升機器學習模型的預測能力。

## 3.1 特徵建構與轉換

### 3.1.1 特徵衍生 (Feature Derivation)

*   **定義**：利用現有欄位計算出新的變數。
*   **範例**：利用「銷售金額」與「瀏覽次數」，計算出「銷售金額/瀏覽次數」(平均客單價/轉換率指標)。此動作屬於**特徵衍生** (B)。

### 3.1.2 特徵轉換 (Feature Transformation)

*   **目的**：改善變數的分佈特性，使其更符合模型假設。
*   **Box-Cox 轉換**：
    *   當迴歸模型的應變數 $Y$ 分佈明顯**右偏**，且變異數隨 $X$ 增大而增加 (異質變異性) 時，可對 $Y$ 進行 **Box-Cox 轉換** (B) 或對數轉換，以穩定變異數並使分佈接近常態。

## 3.2 降維技術 (Dimensionality Reduction)

### 3.2.1 主成分分析 (PCA)

*   **原理**：透過線性組合將原始變數轉換為一組互不相關的主成分 (Principal Components)，並保留最大的變異量。
*   **注意事項**：
    *   PCA 對變數的**尺度 (Scale) 非常敏感**。
    *   若變數間量級差異極大 (如金額 $10^5$ vs 年齡 $10^2$)，變異量大的變數會主導主成分。
    *   **解法**：在進行 PCA 前，務必先進行**標準化 (Standardization)** (D)。

## 3.3 特徵關聯性分析

### 3.3.1 相關係數 (Correlation Coefficient)

*   **皮爾森相關係數 (Pearson Correlation)**：
    *   衡量兩個連續變數間**線性關係**的強度與方向 (C)。
    *   範圍：[-1, 1]。
*   **視覺化**：
    *   **散佈圖 (Scatter Plot)**：觀察兩變數關係。
    *   **熱力圖 (Heatmap)**：呈現多變數間的相關係數矩陣 (D)。

## 3.4 處理不平衡資料 (Imbalanced Data)

在分類問題中，若某類別樣本數遠少於其他類別 (如罕見疾病、詐欺偵測)。

### 3.4.1 過採樣 (Oversampling)

*   **隨機過採樣 (Random Oversampling)**：複製少數類樣本。
    *   **風險**：可能導致**過擬合 (Overfitting)** (A)，因為模型記住了重複的樣本。
*   **SMOTE (Synthetic Minority Over-sampling Technique)**：
    *   生成**合成**的少數類樣本，而非單純複製。
    *   **策略**：在少數類樣本連線上隨機生成新點。
    *   **優點**：提升模型對少數類的偵測能力，同時避免過擬合 (C)。

### 3.4.2 欠採樣 (Undersampling)

*   減少多數類樣本。可能導致資訊流失。
