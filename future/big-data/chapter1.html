第 1 章：統計與機率基礎

本章介紹大數據分析中不可或缺的統計學與機率論基礎，包括描述性統計、機率分佈以及假設檢定等核心概念。

1.1 描述性統計 (Descriptive Statistics)

描述性統計用於彙整與描述數據的特徵。

1.1.1 Z-Score (標準分數)

Z-Score 用於衡量一個數值與平均值的距離，以標準差為單位。

  • 定義：\(Z = \frac{X - \mu}{\sigma}\)
  • 意涵：
    • 若 Z-Score = 0，代表該數值等於平均值。
    • 若 Z-Score = 2，代表該數值比平均值高 2 個標準差 (D)。
    • 若 Z-Score = -1.5，代表該數值比平均值低 1.5 個標準差。
  • 應用：
    • 異常值偵測 (Outlier Detection)：常用標準是 \(|Z| \ge 3\)。例如，若平均交易金額為 2,000 元，標準差為 400 元，某筆交易為 3,200 元，則 \(Z = (3200 - 2000) / 400 = 3\)。因 \(|3| \ge 3\)，應標記為異常值 (A)。

1.1.2 偏態 (Skewness)

偏態衡量資料分佈的不對稱性。

  • 右偏 (Right-skewed / Positive Skewness)：
    • 長尾向右延伸。
    • 平均值 > 中位數。
    • Skewness > 0 (B)。
  • 左偏 (Left-skewed / Negative Skewness)：
    • 長尾向左延伸。
    • 平均值 < 中位數。
    • Skewness < 0。
  • 對稱分佈：Skewness \(\approx\) 0。

1.1.3 累積分佈函數 (CDF)

  • 定義：累積分佈函數 (Cumulative Distribution Function, CDF) 描述隨機變數 \(X\) 小於或等於某個值 \(x\) 的機率，即 \(F(x) = P(X \le x)\)。
  • 對於連續隨機變數，CDF 是機率密度函數 (PDF) 的積分 (B)。

1.2 機率分佈 (Probability Distributions)

1.2.1 常態分佈 (Normal Distribution)

  • 特性：鐘形曲線，對稱於平均值。
  • 應用：
    • 二項分佈的近似：當二項分佈 (Binomial Distribution) 的試驗次數 \(n\) 足夠大，且 \(p\) 不接近 0 或 1 (通常要求 \(np \ge 5\) 且 \(n(1-p) \ge 5\)) 時，可用常態分佈近似。
    • 注意：若僅樣本數大但 \(p\) 極端，近似效果可能不佳，但在大數據場景下，通常 \(n\) 極大可視為近似 (A)。

1.2.2 卜瓦松分佈 (Poisson Distribution)

  • 適用情境：描述在固定時間或空間內，發生某個稀有事件的次數。事件彼此獨立，且發生機率與時間長短成正比。
    • 例如：客服中心每分鐘接到的來電數 (C)、每小時生產線的瑕疵品數。
  • Python 實作：
    • scipy.stats.poisson.pmf(k, mu)：計算發生 \(k\) 次事件的機率 (Probability Mass Function)。
    • scipy.stats.poisson.cdf(k, mu)：計算發生 \(k\) 次或以下事件的累積機率。

1.2.3 指數分佈 (Exponential Distribution)

  • 通常用於描述事件發生的時間間隔。

1.3 假設檢定 (Hypothesis Testing)

1.3.1 t 檢定 (t-test)

  • 單樣本 t 檢定 (One-sample t-test)：檢驗樣本平均數是否顯著異於母體平均數。
    • 判讀：若 p-value > \(\alpha\) (顯著水準)，則無法拒絕虛無假設。
    • 信賴區間：若檢定值 (如 100 萬元) 落在 95% 信賴區間內 (如 [95, 108])，亦代表無法拒絕虛無假設 (C)。

1.3.2 雙比例 Z 檢定 (Two-proportion Z-test)

  • 應用：比較兩個獨立樣本的比例 (Proportion) 是否有顯著差異。
    • 例如：比較兩條生產線的產品良率 (95% vs 97%) (B)。

1.3.3 變異數分析 (ANOVA)

  • 用於比較三組或以上樣本的平均數差異。

1.4 其他統計指標

1.4.1 吉尼不純度 (Gini Impurity)

  • 常用於決策樹分類。
  • 正規化吉尼不純度：若資料標籤分佈極端 (如 A, A, A, A, A, B, B, B, B, B，各佔 50%)，Gini = \(1 - (0.5^2 + 0.5^2) = 0.5\)。若需正規化 (Normalized)，通常指相對於最大可能值的比例，或特定上下文定義。
    • 題目案例：10 筆資料，5A 5B。Gini = 0.5。若正規化至 [0, 1]，則為 1 (D)。(註：一般 Gini 最大值為 0.5 (二元分類)，正規化後為 1)。

1.4.2 分位數迴歸 (Quantile Regression)

  • 當資料分佈非對稱、存在極端值或異質變異 (Heteroscedasticity) 時，傳統線性迴歸 (關注平均值) 可能不適用。
  • 分位數迴歸可聚焦於尾部分位 (Tail Quantiles)，評估極端風險 (D)。
