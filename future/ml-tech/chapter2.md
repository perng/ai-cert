# 第 2 章：特徵工程與資料處理

優質的特徵是模型效能的基石。

## 2.1 特徵選擇與提取

### 2.1.1 資訊增益 (Information Gain)

*   **定義**：衡量特徵對分類結果的不確定性減少程度 (Entropy 下降量)。
*   **應用**：主要用於**決策樹模型** (D) 的節點分裂。

### 2.1.2 主成分分析 (PCA)

*   **原理**：線性降維，保留最大變異量。
*   **解釋變異量**：
    *   若特徵值 $\lambda_1=6.0, \lambda_2=3.0, \lambda_3=1.0$，總變異量 $6+3+1=10$。
    *   前兩個主成分解釋 $(6+3)/10 = 90\%$。
    *   若門檻為 80%，保留前兩個主成分即可 (A)。
*   **去噪應用**：
    *   PCA 可用於影像降噪，但需設定保留的成分數量。
    *   若程式碼未設定 `n_components` (如 `pca = PCA()`)，則預設保留所有成分，**無法發揮降噪效果** (B)。

## 2.2 特徵處理技術

### 2.2.1 特徵縮放 (Feature Scaling)

*   **重要性**：對於**以距離為基礎**的模型 (KNN, SVM)，特徵縮放最為關鍵 (A)，以免數值大的特徵主導距離計算。
*   **標準化 (Standardization)**：
    *   公式：$z = \frac{x - \mu}{\sigma}$。
    *   程式碼：`X -= X.mean(axis=0); X /= X.std(axis=0)`。
    *   目的：防止梯度爆炸或消失 (D)，加速收斂。
    *   **注意**：標準化不是將資料壓縮到 [0, 1] (那是 Min-Max)，也不是將標準差調為 0 (是調為 1)。

### 2.2.2 互動特徵 (Interaction Features)

*   **目的**：捕捉特徵間的關聯影響 (如價格與滿意度的交互作用)。
*   **方法**：將兩個或多個特徵進行**乘積**或交互組合 (C)。

### 2.2.3 正則化特徵選擇

*   **L1 正則化 (Lasso)**：
    *   特性：產生**稀疏模型 (Sparse Model)**，使部分權重收斂為 0 (C)。
    *   應用：自動篩選特徵 (D)。
*   **L2 正則化 (Ridge)**：
    *   特性：抑制權重大小，但不會變為 0。適合處理共線性。

## 2.3 程式實作與運算

### 2.3.1 Numpy 運算

*   `v1 * v2`：元素對應相乘 (Element-wise multiplication)。
    *   `[1,2,3] * [4,5,6] = [4, 10, 18]` (B 錯誤)。
*   `np.dot(v1, v2)`：內積。
    *   $1\times4 + 2\times5 + 3\times6 = 4+10+18 = 32$ (C 正確)。
*   `np.linalg.inv`：反矩陣。`eig`：特徵值。

### 2.3.2 KNN 交叉驗證實作

*   正確寫法：`cross_val_score(model, X, y, cv=5, scoring="accuracy")`。
*   錯誤寫法：多類別分類若用 `scoring="f1"` 會報錯，需指定 `f1_macro` 或 `f1_micro`。
*   題目中，程式碼 A (指定 accuracy) 與 C (指定 cv=5) 為正確用法 (B)。
