# 前言 {.unnumbered}

本學科「機器學習技術與應用」深入探討機器學習的核心技術、模型評估方法、深度學習架構以及實際應用場景中的挑戰與解決方案。

## 學習目標

1.  **模型評估與驗證**：掌握交叉驗證、混淆矩陣指標（Precision, Recall, F1）、殘差分析等評估技術。
2.  **特徵工程**：學習特徵縮放、選擇（L1/L2 正則化）、降維（PCA）及處理不平衡資料的策略。
3.  **深度學習架構**：深入理解 CNN、RNN、LSTM 及 Transformer 的運作原理與適用場景。
4.  **模型訓練與優化**：熟悉梯度下降、反向傳播、激活函數、優化器（Adam, Momentum）及超參數調整（Grid/Random Search）。
5.  **進階演算法**：探討 XGBoost、DBSCAN、AutoML 及貝氏推論等進階技術。
6.  **AI 安全與倫理**：了解同態加密、差分隱私及模型可解釋性等議題。
