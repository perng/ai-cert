# 第五章：特徵工程與數據分析

本章將探討處理複雜數據的特徵工程技術，以及分群與時間序列分析的進階方法。

## 1. 特徵工程實務

### 處理巢狀結構資料 (JSON)

在分析系統日誌 (System Logs) 或 NoSQL 資料庫時，常遇到**半結構化資料**，其中包含巢狀欄位 (Nested Fields，例如 JSON 裡還有 JSON)。

*   **挑戰**：傳統機器學習模型（如 Random Forest）無法直接吃 JSON 格式。
*   **策略**：
    1.  **展開 (Flatten)**：設計**遞迴函式 (Recursive Function)** 將巢狀欄位展開成平面欄位。
    2.  **聚合 (Aggregation)**：由於日誌通常是連續發生的，應基於**時間窗口 (Time Window)**（例如每 5 分鐘）進行聚合，計算統計量（如錯誤次數、平均回應時間）作為特徵。
*   **錯誤作法**：
    *   直接忽略巢狀內容（損失關鍵資訊）。
    *   使用 RNN 直接讀取原始 JSON 字串（效率極低且雜訊多）。

### 混合型特徵處理

當資料集同時包含連續型（如金額、年齡）與類別型（如地區、職業）特徵時：

*   **最佳作法**：
    1.  **連續特徵**：進行**標準化 (Standardization)** 或正規化，確保數值範圍一致，避免大數值主導模型。
        *   **公式**：$z = \frac{x - \mu}{\sigma}$ （減去平均值，除以標準差）
    2.  **類別特徵**：採用**目標編碼 (Target Encoding)** 或嵌入 (Embedding)。相比 One-Hot Encoding，目標編碼更能處理高基數 (High Cardinality) 類別。
    3.  **交互特徵 (Interaction Features)**：生成特徵組合（如「地區 x 職業」），以提升模型對非線性關係的捕捉能力。

### 多重共線性 (Multicollinearity)

當特徵之間高度相關（如「房間數」與「坪數」、「身高」與「腿長」）時，會導致線性迴歸係數不穩定，解釋性變差。

*   **解決方案**：
    1.  **PCA (主成分分析)**：將相關特徵轉換為彼此獨立的主成分 (Principal Components)。
    2.  **LASSO 迴歸 (L1 正則化)**：LASSO 具有**特徵選擇**功能，能將不重要或共線特徵的係數壓縮為零 (Zeroing out)，適合處理此問題。

### 降維技術：PCA

*   **情境**：將 1024 維的影像特徵降至 100 維，再輸入 SVM 進行訓練。
*   **效益**：
    *   **降低訓練時間**：維度減少，計算量大幅下降。
    *   **減少過擬合風險 (Overfitting)**：去除雜訊與冗餘特徵，讓模型專注於主要變異方向，往往能提升模型的泛化能力。
*   **迷思**：PCA 不一定能提升準確率（有時會掉），也不一定能處理非線性資料（PCA 本質是線性的）。

## 2. 分群演算法：DBSCAN

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) 是一種基於密度的分群演算法，不需要預先指定分群數量 (K)。

*   **核心參數**：
    *   **Epsilon (ε, 鄰域半徑)**：定義密度的距離閾值。
    *   **MinPts (最小點數)**：定義形成一個核心點 (Core Point) 所需的最小鄰居數。
*   **運作原理**：
    1.  從一個點開始，如果它的 ε 半徑內有超過 MinPts 個點（即 $Distance(p, q) \le \epsilon$ 的點數量 $\ge MinPts$），就形成一個群聚。
    2.  不斷向外擴張，直到密度不足為止。
    3.  無法被歸類的點標記為**雜訊 (Noise)**。
*   **優勢**：能發現**任意形狀**的群聚（如彎月形、同心圓），且能自動識別雜訊。
*   **效能優化**：
    *   **問題**：當資料量大且維度高時，計算所有點對點的距離非常耗時 ($O(N^2)$)。
    *   **解法**：採用**高效率的距離索引結構**，如 **KD-Tree 或 Ball Tree**，以加速最近鄰搜尋，將複雜度降至 $O(N \log N)$。

## 3. 時間序列分析：ARIMA

ARIMA (AutoRegressive Integrated Moving Average) 是經典的時間序列預測模型。

*   **模型診斷 (Diagnostics)**：建立模型後，必須檢查**殘差 (Residuals)**。
*   **理想殘差**：應該是**白噪音 (White Noise)**，即隨機分佈，無任何模式。
*   **異常訊號**：
    *   若殘差隨時間呈現**週期性波動**。
    *   **自相關函數 (ACF)** 顯示在多個時滯 (Lag) 上顯著不為零。
*   **結論**：這代表模型存在**配適不足 (Underfitting)**。模型未能捕捉到資料中的所有時間依賴性或季節性模式，殘差裡還藏著規律沒被挖出來。
*   **修正**：需重新調整參數（如增加 AR 或 MA 的階數 p, q），或加入季節性項 (SARIMA)。
