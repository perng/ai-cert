Python 的定位與執行方式

Python 被稱為動態型別語言，主要代表什麼意思？
#8001
  1. Python 程式一定會自動使用 GPU 執行
  2. 變數宣告時必須明確指定資料型別
  3. 變數本身不固定型別，型別會跟著當前指派的值而定
  4. Python 只能在 Jupyter Notebook 中執行
💡 動態型別表示變數名稱不綁定固定型別，執行時的值決定其型別。

Python 的 tuple 與 list 相比，主要差異是什麼？
#8072
  1. tuple 有序但不可變，list 有序且可變
  2. tuple 只能儲存浮點數，list 只能儲存字串
  3. tuple 會自動訓練模型，list 不會
  4. tuple 無法被函式回傳
💡 tuple 是不可變序列，適合表示固定組合；list 是可變序列，適合持續新增或修改元素。

NumPy 陣列與向量化

NumPy 陣列相較於 Python list，在數值運算上通常較有效率的主要原因是什麼？
#8011
  1. NumPy 陣列完全不需要記憶體
  2. NumPy 陣列通常儲存同質資料並使用底層最佳化運算
  3. NumPy 陣列只能儲存字串
  4. NumPy 會自動替所有模型調整超參數
💡 NumPy ndarray 通常以同質型別與連續記憶體表示資料，並透過底層最佳化提升數值運算效率。
chap-m6-ch2 sec-numpy-array-vectorization
向量化 (Vectorization) 的核心精神是什麼？
#8012
  1. 儘量使用 Python 層逐筆 for 迴圈完成數值計算
  2. 用陣列層級的批次運算取代逐筆迴圈
  3. 把所有資料都轉成文字
  4. 只使用 GPU 而不使用 CPU
💡 向量化透過陣列運算一次處理多筆資料，通常比 Python 逐筆迴圈更快。
