敘述統計

在敘述統計中，哪一個指標最容易受到極端值 (Outliers) 的影響？
#3101
  1. 眾數 (Mode)，數據中出現次數最多的數值
  2. 四分位距 (IQR)，第三四分位數與第一四分位數的差
  3. 平均數 (Mean)，所有數據的總和除以數據個數
  4. 中位數 (Median)，將數據排序後位於中間的數值
💡 平均數涉及所有數值的總和，因此極端值會顯著拉高或拉低平均數。中位數和眾數則相對穩健。

變異數 (Variance) 與標準差 (Standard Deviation) 的關係為何？
#3102
  1. 標準差是變異數的平方 (Variance Squared)
  2. 標準差是變異數的平方根 (Square Root of Variance)
  3. 兩者在數學上完全無關
  4. 變異數是標準差的平方根 (Square Root of Standard Deviation)
💡 標準差是變異數的平方根 ($\sigma = \sqrt{\sigma^2}$)，這使得標準差的單位與原始數據一致，更直觀。

機率分佈

根據「68-95-99.7 法則」，在常態分佈中，約有多少比例的數據落在平均值正負兩個標準差 ($\mu \pm 2\sigma$) 範圍內？
#3103
  1. 約 50% 的數據
  2. 約 68% 的數據
  3. 約 99.7% 的數據
  4. 約 95% 的數據
💡 常態分佈的特性是：$\mu \pm 1\sigma$ 涵蓋約 68%，$\mu \pm 2\sigma$ 涵蓋約 95%，$\mu \pm 3\sigma$ 涵蓋約 99.7%。
chap-m1-ch1 sec-prob-stats
哪一種機率分佈最適合用來描述「投擲一枚硬幣 10 次，出現正面 5 次的機率」？
#3104
  1. 泊松分佈 (Poisson Distribution)，描述單位時間內事件發生的次數
  2. 指數分佈 (Exponential Distribution)，描述事件發生的時間間隔
  3. 二項式分佈 (Binomial Distribution)，描述 n 次獨立伯努利試驗中成功的次數
  4. 常態分佈 (Normal Distribution)，描述許多自然現象的連續機率分佈
💡 二項式分佈描述的是在 $n$ 次獨立的伯努利試驗（只有成功/失敗兩種結果）中，成功 $k$ 次的機率。
chap-m1-ch1 sec-prob-stats
貝氏定理 (Bayes' Theorem) 的核心公式是？
#3111
  1. $P(A|B) = P(B|A)P(A) / P(B)$
  2. $P(A|B) = P(B|A)$，這通常是不成立的
  3. $P(A|B) = P(A) + P(B)$，這是互斥事件的機率公式
  4. $P(A|B) = P(A)P(B)$，這是獨立事件的機率公式
💡 貝氏定理描述了在已知 B 發生的條件下 A 發生的機率，公式為 $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$。
chap-m1-ch1 sec-prob-stats
兩個事件 A 和 B 獨立 (Independent) 意味著？
#3116
  1. $P(A \cap B) = P(A)P(B)$，即兩者同時發生的機率等於各自機率的乘積
  2. $P(A \cap B) = P(A) + P(B)$，這是錯誤的公式
  3. $P(A \cap B) = 0$，這是互斥事件
  4. $P(A|B) = 0$，表示 B 發生時 A 不可能發生
💡 若 A 與 B 獨立，則 A 的發生不影響 B，且兩者同時發生的機率等於各自發生機率的乘積。
chap-m1-ch1 sec-prob-stats
期望值 (Expectation) $E[X]$ 在幾何上對應於機率分佈的？
#3117
  1. 重心 (Center of Mass) 或平均位置，代表分佈的平衡點
  2. 面積 (Area)，機率密度函數下的總面積恆為 1
  3. 最高點 (Peak)，即眾數
  4. 寬度 (Width)，即變異數或標準差
💡 期望值是隨機變數的加權平均，幾何上對應於機率密度函數圖形的重心。
chap-m1-ch1 sec-prob-stats
中央極限定理 (Central Limit Theorem) 指出，當樣本數夠大時，樣本平均數的抽樣分佈會趨近於？
#3123
  1. 指數分佈 (Exponential Distribution)
  2. 常態分佈 (Normal Distribution)
  3. 均勻分佈 (Uniform Distribution)
  4. 泊松分佈 (Poisson Distribution)
💡 中央極限定理是統計學的基石，指出無論母體分佈為何，只要樣本數夠大，樣本平均數的分佈都會近似常態分佈。
chap-m1-ch1 sec-prob-stats
條件機率 $P(A|B)$ 的定義是？
#3127
  1. 在 A 發生的條件下 B 發生的機率 (Probability of B given A)
  2. A 和 B 同時發生的機率 (Joint Probability)
  3. A 或 B 發生的機率 (Union Probability)
  4. 在 B 發生的條件下 A 發生的機率 (Probability of A given B)
💡 $P(A|B)$ 讀作「在 B 給定下 A 的機率」，即已知 B 發生後 A 發生的可能性。
chap-m1-ch1 sec-prob-stats
伯努利試驗 (Bernoulli Trial) 的特點是？
#3131
  1. 每次試驗結果互相影響 (Dependent Trials)
  2. 有無限多種可能的結果 (Infinite Outcomes)
  3. 只有兩種可能的結果（成功/失敗）(Binary Outcome)
  4. 結果是連續的數值 (Continuous Value)
💡 伯努利試驗是最簡單的隨機試驗，只有兩種互斥結果，如投硬幣。
chap-m1-ch1 sec-prob-stats
聯合機率 (Joint Probability) $P(A, B)$ 表示？
#3137
  1. A 或 B 發生的機率 (Union Probability)
  2. A 發生的機率 (Marginal Probability)
  3. A 發生且 B 不發生的機率 (Difference Probability)
  4. A 和 B 同時發生的機率 (Intersection Probability)
💡 聯合機率描述兩個事件同時發生的可能性。

假設檢定

在假設檢定中，p-value 代表什麼意義？
#3105
  1. 對立假設 ($H_1$) 為真的機率
  2. 實驗完全失敗的機率
  3. 虛無假設 ($H_0$) 為真的機率
  4. 在虛無假設 ($H_0$) 為真的前提下，觀察到當前數據或更極端情況的機率
💡 p-value 是在虛無假設成立的條件下，出現目前觀測結果或更極端結果的機率。p 值越小，拒絕 $H_0$ 的證據越強。
chap-m1-ch1 sec-prob-stats
型一錯誤 (Type I Error) 又稱為？
#3120
  1. 系統誤差 (Systematic Error)
  2. 隨機誤差 (Random Error)
  3. 偽陽性 (False Positive)，即沒病判有病
  4. 偽陰性 (False Negative)，即有病判沒病
💡 型一錯誤是指虛無假設為真卻被拒絕，即「無中生有」，稱為偽陽性。
chap-m1-ch1 sec-prob-stats
顯著水準 (Significance Level) $\alpha$ 通常設定為？
#3121
  1. 0.5 (50%)
  2. 0.05 (5%)，這是最常用的標準
  3. 0.001 (0.1%)
  4. 0.95 (95%)
💡 統計學中常用的顯著水準是 0.05 (5%)，表示我們願意承擔 5% 的機率犯型一錯誤。
chap-m1-ch1 sec-prob-stats
對立假設 (Alternative Hypothesis, $H_1$) 通常代表？
#3128
  1. 研究者想要證明的效應或差異 (Effect or Difference to be Proven)
  2. 現狀或無效應 (Status Quo or No Effect)
  3. 實驗過程失敗 (Experiment Failure)
  4. 數據收集錯誤 (Data Error)
💡 虛無假設 $H_0$ 通常代表「無差異」，而對立假設 $H_1$ 是研究者希望收集證據支持的假設（有差異、有效應）。
chap-m1-ch1 sec-prob-stats
雙尾檢定 (Two-tailed Test) 用於檢驗？
#3134
  1. 參數是否大於某個特定值 (Greater than)
  2. 樣本數是否足夠大 (Sample Size Sufficiency)
  3. 參數是否不等於某個值（差異可能在任何方向）(Not equal to)
  4. 參數是否小於某個特定值 (Less than)
💡 雙尾檢定關注的是「有無差異」，而不論差異的方向（大於或小於）。
chap-m1-ch1 sec-prob-stats
自由度 (Degrees of Freedom) 通常與什麼有關？
#3139
  1. 樣本數 (Sample Size)
  2. 顯著水準 (Significance Level)
  3. 母體的大小 (Population Size)
  4. 變數的測量單位 (Unit of Measurement)
💡 自由度通常取決於樣本數（如 $n-1$），影響 t 分佈或卡方分佈的形狀。

線性代數

若兩個向量的內積 (Dot Product) 為 0，代表這兩個向量的幾何關係為何？
#3106
  1. 兩向量平行 (Parallel)
  2. 兩向量長度相等 (Equal Length)
  3. 兩向量垂直 (Orthogonal)
  4. 兩向量方向相反 (Opposite Direction)
💡 內積公式為 $a \cdot b = ||a|| ||b|| \cos \theta$。當內積為 0 時，$\cos \theta = 0$，即 $\theta = 90^\circ$，表示兩向量垂直（正交）。
chap-m1-ch1 sec-linear-algebra
對於矩陣 $A$，若 $Av = \lambda v$ (其中 $v \neq 0$)，則 $\lambda$ 稱為 $A$ 的什麼？
#3107
  1. 逆矩陣 (Inverse Matrix)，代表變換的逆運算
  2. 特徵值 (Eigenvalue)，代表變換的縮放倍率
  3. 特徵向量 (Eigenvector)，代表變換的方向
  4. 行列式 (Determinant)，代表變換的面積縮放率
💡 滿足 $Av = \lambda v$ 的純量 $\lambda$ 稱為矩陣 $A$ 的特徵值，向量 $v$ 稱為對應的特徵向量。
chap-m1-ch1 sec-linear-algebra
單位矩陣 (Identity Matrix) $I$ 的特性是？
#3112
  1. 行列式為 0 (Singular Matrix)
  2. 對角線元素為 1，其餘為 0 (Diagonal Matrix with 1s)
  3. 對角線元素為 0，其餘為 1
  4. 所有元素皆為 1 (All Ones Matrix)
💡 單位矩陣是對角線上元素為 1，其餘元素為 0 的方陣。任何矩陣與其相乘都等於原矩陣。
chap-m1-ch1 sec-linear-algebra
矩陣乘法 $AB$ 成立的條件是？
#3113
  1. A 的列數 (Rows) 等於 B 的行數 (Columns)
  2. A 的行數 (Columns) 等於 B 的列數 (Rows)
  3. A 和 B 必須是方陣 (Square Matrices)
  4. A 和 B 的維度完全相同 (Same Dimensions)
💡 若 A 是 $m \times n$ 矩陣，B 是 $p \times q$ 矩陣，則必須 $n = p$ (A 的行數等於 B 的列數) 才能相乘。
chap-m1-ch1 sec-linear-algebra
轉置矩陣 (Transpose Matrix) $A^T$ 是如何從 $A$ 得到的？
#3118
  1. 將所有元素變號 (Negation)
  2. 將矩陣旋轉 90 度 (Rotate 90 degrees)
  3. 將所有元素取倒數 (Reciprocal)
  4. 將列與行互換 (Swap Rows and Columns)
💡 轉置矩陣是將原矩陣的第 $i$ 列變成第 $i$ 行，即 $A^T_{ij} = A_{ji}$。
chap-m1-ch1 sec-linear-algebra
向量的 L2 範數 (Norm) 通常用來表示向量的？
#3119
  1. 向量所有元素的總和 (Sum of Elements)
  2. 向量的維度 (Dimension)
  3. 向量的方向 (Direction)
  4. 向量的長度 (Length) 或歐幾里得距離 (Euclidean Distance)
💡 L2 範數 $||x||_2 = \sqrt{\sum x_i^2}$ 代表向量在歐幾里得空間中的長度。
chap-m1-ch1 sec-linear-algebra
兩個非零向量正交 (Orthogonal) 時，它們的夾角是？
#3124
  1. 0 度 (平行)
  2. 180 度 (反向)
  3. 45 度
  4. 90 度 (垂直)
💡 正交即垂直，夾角為 90 度 ($\pi/2$)。

矩陣的秩 (Rank) 代表什麼？
#3125
  1. 矩陣的行數 (Number of Columns)
  2. 矩陣中線性獨立的列 (或行) 的最大數量 (Number of Linearly Independent Rows/Cols)
  3. 矩陣中所有元素的總和 (Sum of Elements)
  4. 矩陣的列數 (Number of Rows)
💡 秩反映了矩陣所包含的資訊量或維度，即線性獨立向量的個數。
chap-m1-ch1 sec-linear-algebra
逆矩陣 (Inverse Matrix) $A^{-1}$ 滿足什麼性質？
#3129
  1. $AA^{-1} = A$
  2. $A^{-1} = A^T$ (正交矩陣 Orthogonal Matrix)
  3. $AA^{-1} = 0$ (零矩陣 Zero Matrix)
  4. $AA^{-1} = I$ (單位矩陣 Identity Matrix)
💡 矩陣與其逆矩陣相乘等於單位矩陣 $I$。

兩個向量線性相依 (Linearly Dependent) 表示？
#3132
  1. 它們的內積為 0 (Dot Product is Zero)
  2. 它們互相垂直 (Orthogonal)
  3. 它們長度相等 (Equal Length)
  4. 其中一個向量可以表示為另一個向量的純量倍數 (Scalar Multiple)
💡 線性相依意味著向量之間存在冗餘，一個向量可以由其他向量線性組合而成（在二維中即平行）。

張量 (Tensor) 是什麼的推廣？
#3135
  1. 純量、向量和矩陣到更高維度的推廣 (Generalization to Higher Dimensions)
  2. 僅限於二維矩陣 (Matrix Only)
  3. 僅限於一維向量 (Vector Only)
  4. 複數系統 (Complex Numbers)
💡 張量是多維陣列的通稱。0 階張量是純量，1 階是向量，2 階是矩陣，3 階以上稱為高階張量。

矩陣的跡 (Trace) 是指？

  1. 矩陣最後一行元素的總和 (Sum of Last Column)
  2. 矩陣第一列元素的總和 (Sum of First Row)
  3. 矩陣所有元素的乘積 (Product of Elements)
  4. 矩陣主對角線元素的總和 (Sum of Diagonal Elements)
💡 Trace 是方陣主對角線上所有元素的和，具有基底變換不變性等重要性質。

情境：若兩個向量的內積為 0，代表它們在幾何上的關係是？

  2. 兩向量正交或垂直 (Orthogonal / Perpendicular)

  4. 兩向量方向相反 (Opposite)

情境：矩陣 $A$ 的特徵值 $\lambda$ 和特徵向量 $v$ 滿足什麼關係？

  1. $Av = v$
  2. $Av = 0$

  4. $A = \lambda v$

  1. $A$ 的第 $i$ 列與 $B$ 的第 $j$ 行的內積 (Dot Product of Row i of A and Column j of B)

  4. $A_{ij} * B_{ij}$ (Element-wise Multiplication)
💡 矩陣乘法的定義是左矩陣的列向量與右矩陣的行向量做內積。

  1. 轉置矩陣 (Transpose Matrix)

  4. 對角矩陣 (Diagonal Matrix)

微積分與最佳化

函數 $f(x)$ 在某一點的導數 (Derivative) 代表什麼幾何意義？
#3108
  1. 曲線下的面積 (Area under Curve)
  2. 曲線在該點的切線斜率 (Slope of Tangent Line)，代表瞬時變化率
  3. 曲線在該點的高度 (Function Value)
  4. 曲線與 x 軸的交點 (Root)
💡 導數定義為函數在某一點的切線斜率，反映了函數在該點的瞬時變化率。
chap-m1-ch1 sec-calculus-optimization
梯度下降 (Gradient Descent) 演算法中，為了最小化損失函數，我們應該沿著梯度的哪個方向更新參數？
#3109
  1. 隨機選擇一個方向 (Random Direction)
  2. 沿著梯度的反方向 (Opposite to Gradient)，即函數下降最快的方向
  3. 與梯度垂直的方向 (Orthogonal Direction)
  4. 沿著梯度的方向 (Gradient Direction)，即函數上升最快的方向
💡 梯度指向函數增長最快的方向，因此為了尋找最小值（最小化損失），我們應沿著梯度的反方向（下降最快的方向）移動。

情境：你正在為一個即時詐欺偵測系統建立模型。數據集包含數百萬筆交易，但其中只有 0.1% 是詐欺（嚴重類別不平衡）。在進行特徵工程與預處理時，你應避免下列哪種操作？

  2. 使用 SMOTE 進行過採樣 (Oversampling)，增加詐欺樣本
  3. 直接使用準確率 (Accuracy) 作為特徵選擇的評估指標，因為這會產生誤導
  4. 使用欠採樣 (Undersampling) 減少正常交易數量，平衡數據集
💡 在極度不平衡的數據中，準確率會產生誤導（盲猜「正常」就有 99.9% 準確率）。若基於準確率來選擇特徵，可能會選出對偵測詐欺毫無幫助的特徵，應改用 F1-score 或 AUC。

情境：你正在處理一個包含「國家」特徵的全球銷售數據集，共有 180 個不同的國家。若直接使用 One-Hot Encoding，會產生 180 個新欄位，導致維度災難。下列哪種替代方案最不合適？
#3242
  1. Target Encoding：用各國的平均銷售額代替國家名稱
  2. Label Encoding：按字母順序將國家編碼為 1~180 的整數，這會引入無意義的順序關係
  3. Frequency Encoding：用各國在數據中出現的頻率代替
  4. 將低頻國家合併為 "Other" 類別，再進行 One-Hot Encoding
💡 Label Encoding 會賦予國家一個無意義的順序（如阿富汗=1, 辛巴威=180），模型可能會錯誤地學習到「國家編號越大，銷售額越高」這種不存在的線性關係。Target Encoding 或合併低頻類別是更好的選擇。

情境：你正在訓練一個深層神經網路，發現前幾層的權重幾乎不更新，導致模型無法學習。檢查後發現你使用了 Sigmoid 活化函數。這是什麼問題？應如何解決？
#3441
  1. 梯度爆炸；應使用梯度剪裁 (Exploding Gradient / Gradient Clipping)
  2. 梯度消失；應改用 ReLU 活化函數 (Vanishing Gradient / Use ReLU)
  3. 學習率過大；應降低學習率 (High Learning Rate / Decrease Rate)
  4. 過擬合；應使用 Dropout (Overfitting / Use Dropout)
💡 Sigmoid 的導數最大值僅為 0.25，且在飽和區趨近於 0。在深層網路中，多個小於 1 的導數連乘會導致梯度迅速消失。改用 ReLU (導數為 1) 是標準解決方案。

情境：你使用 Adam 最佳化器訓練模型，初期損失下降很快，但到後期損失在一個較高值附近震盪，無法進一步下降。你應該嘗試調整什麼？
#3442
  1. 降低學習率 (Learning Rate Decay)
  2. 增加批次大小 (Increase Batch Size)
  3. 增加模型層數 (Increase Layers)
  4. 更換成 SGD (Switch to SGD)
💡 雖然 Adam 有自適應學習率，但基礎學習率若設得太大，後期仍可能導致在最小值附近震盪。手動或自動降低學習率 (Learning Rate Schedule) 可以幫助模型在最後階段「沉澱」到更佳的極小值。

情境：你的模型在訓練集上表現極好 (Loss 接近 0)，但在測試集上表現很差。你決定使用 Dropout。請問 Dropout 應該加在哪裡？測試階段 (Inference) 需要保留 Dropout 嗎？
#3443
  1. 隨便加；測試時保留 (Random / Keep)
  2. 加在輸出層；測試時保留 (Output Layer / Keep)
  3. 加在隱藏層後；測試時應移除 (或將權重乘以保留率) (Hidden Layer / Remove or Scale)
  4. 加在輸入層；測試時保留 (Input Layer / Keep)
💡 Dropout 通常加在全連接層之後。在訓練時它隨機關閉神經元以防止過擬合；在測試時，我們希望利用整個網路的能力，因此不應關閉神經元，但需要對權重進行縮放 (Scaling) 以保持期望值一致。

情境：你正在處理一個多標籤分類問題 (Multi-label Classification)，即一張圖片可能同時包含「貓」和「狗」。你的輸出層應該有多少個神經元？使用什麼活化函數？
#3444
  1. N 個神經元 (N=類別數)；Softmax (N Neurons / Softmax)
  2. 1 個神經元；Sigmoid (1 Neuron / Sigmoid)
  3. N 個神經元；ReLU (N Neurons / ReLU)
  4. N 個神經元 (N=類別數)；Sigmoid (N Neurons / Sigmoid)
💡 Softmax 強制所有類別機率和為 1，意味著類別互斥（單選）。對於多標籤問題（複選），每個類別是獨立的，應對每個輸出節點獨立使用 Sigmoid，使其輸出代表該類別存在的機率 (0~1)。

情境：在訓練過程中，Loss 突然變成 NaN (Not a Number)。這最可能是什麼原因造成的？應如何排查？
#3445
  1. 數據量太少 (Insufficient Data)
  2. 梯度爆炸 (Exploding Gradient) 或除以零錯誤 (Division by Zero)
  3. 模型太簡單 (Model too Simple)
  4. 學習率過小 (Learning Rate too Small)
💡 Loss 變 NaN 通常意味著數值計算溢出。常見原因包括學習率過大導致參數更新飛出邊界、梯度爆炸（特別是在 RNN 中），或在計算 Log 時輸入了 0 或負數。梯度剪裁和降低學習率是常見對策。
