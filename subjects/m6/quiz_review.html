Basic Python Language

Python 的定位與執行方式

Python 被稱為動態型別語言，主要代表什麼意思？
#8001
  1. Python 程式一定會自動使用 GPU 執行
  2. 變數宣告時必須明確指定資料型別
  3. 變數本身不固定型別，型別會跟著當前指派的值而定
  4. Python 只能在 Jupyter Notebook 中執行
💡 動態型別表示變數名稱不綁定固定型別，執行時的值決定其型別。

💡 type hints 主要提供型別意圖與靜態分析資訊，不等於執行時強制型別檢查。

NumPy 與 Pandas

NumPy 陣列與向量化

NumPy 陣列相較於 Python list，在數值運算上通常較有效率的主要原因是什麼？
#8011
  1. NumPy 陣列完全不需要記憶體
  2. NumPy 陣列通常儲存同質資料並使用底層最佳化運算
  3. NumPy 陣列只能儲存字串
  4. NumPy 會自動替所有模型調整超參數
💡 NumPy ndarray 通常以同質型別與連續記憶體表示資料，並透過底層最佳化提升數值運算效率。
chap-m6-ch2 sec-numpy-array-vectorization
向量化 (Vectorization) 的核心精神是什麼？
#8012
  1. 儘量使用 Python 層逐筆 for 迴圈完成數值計算
  2. 用陣列層級的批次運算取代逐筆迴圈
  3. 把所有資料都轉成文字
  4. 只使用 GPU 而不使用 CPU
💡 向量化透過陣列運算一次處理多筆資料，通常比 Python 逐筆迴圈更快。
chap-m6-ch2 sec-numpy-array-vectorization

Shape、Broadcasting 與矩陣運算

在 NumPy 與深度學習中，理解 shape 最主要是為了避免什麼問題？
#8013
  1. 避免矩陣或張量維度不相容造成運算錯誤
  2. 避免 Python 程式使用函式
  3. 避免資料集需要標籤
  4. 避免模型產生任何 loss
💡 大量資料與模型運算都依賴維度對齊，shape 不相容會造成矩陣乘法或 broadcasting 錯誤。
chap-m6-ch2 sec-numpy-shape-broadcast

  4. 把整個資料集隨機打亂後忽略欄位名稱
💡 缺失值處理應依據資料語意與模型需求選擇策略，不能盲目套用同一規則。

#8034
  1. 將文字切分成較小單位，例如單字、標點或子詞
  2. 將影像轉成灰階
  3. 將 GPU 記憶體清空

chap-m6-ch4 sec-nltk-text-basics

Stop Words、Stemming 與 Lemmatization

Lemmatization 與 stemming 相比，通常有什麼差異？
#8035
  1. Lemmatization 較嘗試還原成字典詞形，stemming 則較粗略切除字尾
  2. Lemmatization 只能處理影像資料
  3. Stemming 需要 GPU，lemmatization 不需要任何字典
  4. 兩者都是用來 resize 圖片
💡 lemmatization 會依語言詞形規則還原字典形式，stemming 則通常是規則式切字尾。
chap-m6-ch4 sec-nltk-normalization

從文字到特徵

TF-IDF 的核心想法是什麼？
#8036
  1. 常出現在某文件但不常出現在所有文件的詞，通常更能代表該文件
  2. 所有詞都應該得到完全相同權重
  3. 只統計圖片中的邊緣數量
  4. 把文字轉成 BGR 影像
💡 TF-IDF 結合詞頻與反文件頻率，降低過度常見詞的權重。
chap-m6-ch4 sec-nltk-text-features

OpenCV 與 NLTK 的共同觀念

影像與文字前處理共同的重要目標是什麼？
#8037
  1. 將資料轉成模型可接受且訓練與推論一致的數值表示
  2. 讓資料永遠不需要清理
  3. 讓模型完全不需要評估
  4. 把所有資料轉成同一張圖片
💡 非結構化資料都需要讀取、清理、轉換與一致的前處理流程。
chap-m6-ch4 sec-opencv-nltk-common
訓練與部署階段前處理不一致，最可能造成什麼問題？
#8038
  1. 模型推論表現異常或不可預期
  2. Python 無法匯入任何標準函式庫
  3. 所有圖片自動變成高解析度
  4. DataFrame 欄位名稱自動消失
💡 模型訓練時看到的資料分布若和部署推論不同，輸出品質會明顯下降。
chap-m6-ch4 sec-opencv-nltk-common

PyTorch 基礎

Tensor 與裝置

PyTorch Tensor 與 NumPy array 相比，對深度學習特別重要的能力是什麼？
#8041
  1. 可支援 GPU 運算與自動微分
  2. 只能儲存文字
  3. 不允許矩陣運算
  4. 只能在瀏覽器中執行
💡 PyTorch Tensor 支援裝置管理與 autograd，是深度學習訓練的核心。
chap-m6-ch5 sec-pytorch-tensor-device
PyTorch 中模型與輸入 tensor 在不同 device 時，通常會發生什麼？
#8042
  1. 可能產生執行錯誤，因為運算要求資料與模型在同一裝置
  2. 模型會自動轉成 HTML
  3. loss 永遠等於 0
  4. optimizer 會自動刪除資料集
💡 模型參數與輸入 tensor 必須在同一 device，例如都在 CPU 或都在同一張 GPU。
chap-m6-ch5 sec-pytorch-tensor-device

Autograd 與反向傳播

在 PyTorch 中呼叫 loss.backward() 的主要作用是什麼？
#8043
  1. 根據計算圖計算參數梯度
  2. 自動儲存模型到雲端
  3. 將所有 tensor 轉成 Pandas DataFrame
  4. 把文字切成 token
💡 backward 會依照計算圖執行反向傳播，將梯度累積到需要梯度的參數上。
chap-m6-ch5 sec-pytorch-autograd
訓練迴圈中通常需要呼叫 optimizer.zero_grad()，原因是什麼？
#8044
  1. 清空上一輪累積的梯度，避免梯度被不當累加
  2. 將 learning rate 設為 0
  3. 刪除模型所有權重
  4. 關閉 Dataset

#8066
  1. 告訴模型哪些位置是補齊 token，不應當成真實內容

  3. 將影像大小固定為 224x224
  4. 將 optimizer learning rate 設為 0

  3. 防止 Pandas 進行 groupby
  4. 防止 DataLoader 建立 batch
