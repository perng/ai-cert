整合方法

隨機森林 (Random Forest) 是基於哪種整合學習技術？
#6101
  1. Clustering (分群法)，如 K-Means
  2. Stacking (堆疊法)，結合多個模型的預測
  3. Bagging (Bootstrap Aggregating)，如隨機森林
  4. Boosting (提升法)，如 AdaBoost
💡 隨機森林透過 Bagging 技術並行訓練多棵決策樹，每棵樹使用隨機採樣的數據與特徵，最後透過投票或平均來整合結果。

梯度提升 (Gradient Boosting) 的核心思想是？
#6102
  1. 串行訓練模型，每一個新模型都試圖修正前一個模型的殘差 (Residuals)
  2. 隨機選擇特徵進行分割以增加多樣性
  3. 使用元學習器 (Meta-learner) 組合多個基學習器的預測結果
  4. 並行訓練多個獨立的弱學習器
💡 Gradient Boosting 是一種迭代式的 Boosting 方法，每一輪新的弱學習器都是為了減少上一輪模型的殘差 (Residual)。

CatBoost 演算法最大的特色在於擅長處理哪種類型的特徵？
#6105
  1. 類別特徵 (Categorical Features)，無需預先進行 One-hot Encoding
  2. 具有時間依賴性的時間序列特徵 (Time-series Features)
  3. 非結構化的文本特徵 (Text Features)
  4. 高維度的圖像特徵 (Image Features)
💡 CatBoost (Categorical Boosting) 專為處理類別型特徵而設計，能自動處理編碼問題，無需預先進行 One-hot Encoding。

在決策樹中，若「吉尼不純度 (Gini Impurity)」越小，代表該節點的純度如何？
#6106
  1. 越低，表示樣本越混雜
  2. 無法判斷，取決於數據量
  3. 越高，表示樣本越純 (Pure)
  4. 不變，與純度無關
💡 Gini 不純度衡量樣本集合的混雜程度。數值為 0 代表所有樣本屬於同一類（最純），數值越大代表越混雜。

Stacking (堆疊法) 通常使用什麼來組合多個基學習器的預測結果？
#6108
  1. 簡單平均法 (Simple Averaging)
  2. 多數決投票 (Majority Voting)
  3. 元學習器 (Meta-learner)，如 Logistic Regression
  4. 隨機選擇一個基學習器的結果
💡 Stacking 訓練一個第二層模型（元學習器），將第一層多個基學習器的輸出作為輸入特徵，學習如何最佳地組合它們。

LightGBM 相比於 XGBoost 的一個主要優勢是？
#6109
  1. 程式碼實作更為簡單直觀
  2. 支援更多種類的機器學習演算法
  3. 訓練速度更快，且記憶體佔用更低 (Efficiency)
  4. 預測的準確率顯著更高
💡 LightGBM 使用基於直方圖的演算法和 Leaf-wise 生長策略，大幅減少了計算量和記憶體消耗。

隨機森林中的「隨機」體現在哪兩個方面？
#6111
  1. 隨機採樣數據 (Bootstrap Sampling) 和隨機選擇特徵子集 (Feature Subsampling)
  2. 隨機選擇標籤和隨機選擇損失函數
  3. 隨機選擇模型架構和隨機選擇超參數
  4. 隨機初始化權重和隨機停止訓練過程
💡 這種雙重隨機性增加了樹之間的多樣性 (Diversity)，從而降低了整合模型的變異數 (Variance)，防止過擬合。

資訊熵 (Entropy) 越大，代表系統？
#6113
  1. 越有序，資訊量越少
  2. 越混亂，不確定性 (Uncertainty) 越高
  3. 越簡單，結構越單一
  4. 越穩定，變化越少
💡 熵是衡量混亂程度的指標。如果一個集合裡各類別樣本數量相等，熵最大（最難猜）；如果只有一類，熵為 0。

#6115
  1. 控制模型複雜度，防止過擬合 (Overfitting)
  2. 增加特徵的數量
  3. 加速模型的訓練過程
  4. 減少訓練數據的數量
💡 XGBoost 在目標函數中加入了對葉節點數量和權重的懲罰項，這使得它比傳統的 GBDT 更不容易過擬合。

Bagging 的主要目的是降低模型的？
#6117
  1. 訓練誤差 (Training Error)
  2. 偏差 (Bias)，即模型的準確度
  3. 變異數 (Variance)，即模型的穩定性
  4. 計算成本 (Computational Cost)
💡 通過平均多個模型的預測，Bagging 能有效平滑單個模型的隨機誤差，從而降低整體變異數。

Boosting 的主要目的是降低模型的？
#6119
  1. 訓練所需的數據量 (Data Volume)
  2. 數據中的噪音 (Noise)
  3. 偏差 (Bias)，提高模型的擬合能力
  4. 變異數 (Variance)，提高模型的穩定性
💡 Boosting 透過不斷修正前一個模型的錯誤（擬合殘差），逐步逼近真實函數，從而降低偏差。

資訊增益 (Information Gain) 是指？
#6121
  1. 分裂前後資訊熵的差值 (Entropy Difference)，即不確定性的減少量
  2. 分裂後的資訊熵 (Entropy after Split)
  3. 分裂前的資訊熵 (Entropy before Split)
  4. 所有節點資訊熵的總和
💡 決策樹選擇特徵的標準是：哪個特徵能讓系統的混亂程度（熵）下降最多，即資訊增益最大。

隨機森林處理迴歸問題時，通常採用什麼方式整合結果？
#6123
  1. 取所有樹預測值的最小值
  2. 取所有樹預測值的最大值
  3. 計算所有樹預測值的平均值 (Averaging)
  4. 多數決投票 (Majority Voting)
💡 對於數值預測，平均所有樹的預測值是最直觀且有效的整合方式。

哪種 Boosting 演算法使用了 Leaf-wise (按葉子生長) 策略？
#6125
  1. Random Forest (隨機森林)
  2. LightGBM (Light Gradient Boosting Machine)
  3. AdaBoost (Adaptive Boosting)
  4. XGBoost (eXtreme Gradient Boosting)
💡 Leaf-wise 策略每次選擇分裂增益最大的葉子進行分裂，而不是像 Level-wise 那樣一層層長。這通常能得到更深的樹和更高的精度，但也更容易過擬合。

Stacking 的第一層模型通常稱為？
#6126
  1. 元學習器 (Meta-learner)
  2. 弱學習器 (Weak Learners)
  3. 基學習器 (Base Learners)，如 SVM, RF, KNN 等
  4. 強學習器 (Strong Learners)
💡 第一層由多個不同的模型（如 SVM, RF, KNN）組成，它們的輸出被當作第二層模型的輸入特徵。

隨機森林能否計算特徵重要性？
#6128
  1. 只能計算線性特徵的重要性
  2. 不能，隨機森林是黑盒模型
  3. 能，根據特徵在樹分裂中帶來的平均不純度減少量 (Mean Decrease Impurity) 來評估
  4. 只能計算類別特徵的重要性
💡 某個特徵被選為分裂點的次數越多，且帶來的純度提升越大，該特徵就越重要。

XGBoost 支援並行處理 (Parallel Processing)，是指？
#6130
  1. 並行對多個樣本進行預測
  2. 在特徵粒度上進行並行計算 (Feature-level Parallelism)，如計算分裂增益
  3. 並行訓練多棵決策樹
  4. 並行從網路下載數據
💡 Boosting 本質是串行的（樹要一棵棵長），但 XGBoost 優化了建樹過程，能同時在多個 CPU 核心上計算不同特徵的分裂增益，從而加速訓練。

決策樹容易發生什麼問題？
#6132
  1. 欠擬合 (Underfitting)
  2. 計算速度太慢
  3. 無法處理類別型特徵
  4. 過擬合 (Overfitting)，即對訓練數據記憶過深
💡 單棵決策樹如果沒有限制深度，會傾向於死記硬背訓練數據的每一個細節（包括雜訊），導致泛化能力差。隨機森林通過整合多棵樹解決了這個問題。

弱學習器 (Weak Learner) 通常是指？
#6134
  1. 準確率非常低的模型
  2. 訓練時間非常長的複雜模型
  3. 表現僅比隨機猜測好一點點的簡單模型 (Slightly better than random guessing)
  4. 參數量非常龐大的深度學習模型
💡 Boosting 的魔力就在於能將許多個「臭皮匠」（弱學習器）組合成一個「諸葛亮」（強學習器）。

  3. 計算梯度
  4. 用於評估模型的泛化能力 (Generalization Ability)，無需額外的驗證集
  5. 用於訓練模型參數
💡 由於 Bootstrap 採樣，每棵樹大約有 1/3 的數據沒看過（OOB 數據）。用這些數據來測試這棵樹，平均後就是 OOB 誤差，近似於交叉驗證誤差。

  1. 規則的提升效果 (Lift)
  2. 規則的可信程度 (Confidence)
  3. 規則的複雜度或長度

孤立森林 (Isolation Forest) 檢測異常點的核心原理是？
#6104
  1. 異常點距離群集中心的歐氏距離較遠
  2. 異常點的重構誤差 (Reconstruction Error) 較大
  3. 異常點更容易被隨機分割隔離，因此在樹中的路徑長度較短
  4. 異常點周圍的數據密度較高

正規化技術

L1 正規化 (Lasso) 的一個重要特性是？
#6302
  1. 加速模型的訓練收斂速度
  2. 傾向於產生稀疏權重 (Sparse Weights)，可用於特徵選擇
  3. 使權重變得平滑 (Smooth Weights)
  4. 顯著增加模型的複雜度
💡 L1 懲罰項的幾何形狀（菱形）使得最佳解容易落在座標軸上，從而將不重要的特徵權重壓縮為 0。

Dropout 技術在訓練過程中如何運作？
#6303
  1. 隨機丟棄 (歸零) 一部分神經元，防止過度依賴特定特徵
  2. 固定神經元權重不進行更新
  3. 移除所有神經元並重新初始化
  4. 隨機增加額外的神經元以擴展網路
💡 Dropout 就像讓神經元「輪流休息」，防止它們過度依賴彼此（Co-adaptation），從而減少過擬合。

提前停止 (Early Stopping) 的判斷依據是？
#6307
  1. 訓練集誤差 (Training Loss) 不再下降
  2. 驗證集誤差 (Validation Loss) 不再下降甚至開始上升
  3. 訓練時間到達預設的上限
  4. 測試集誤差 (Test Loss) 不再下降
💡 當訓練誤差持續下降但驗證誤差開始上升時，表示模型開始過擬合了，這時應該立即停止訓練。

  2. 允許使用更高的學習率 (Higher Learning Rate)
  3. 具有輕微的正規化效果 (Regularization Effect)
  4. 顯著減少模型參數數量 (Parameter Reduction)
💡 BN 層本身包含可學習的參數（scale 和 shift），因此實際上增加了少量的參數量，而不是減少。

  3. 變小但不為 0 (平滑化)，抑制權重過大
  4. 變為 0 (Sparsity)
💡 L2 懲罰項是權重的平方和，它會抑制過大的權重值，使模型對單一特徵不那麼敏感，從而減少過擬合。

  2. 增加訓練誤差以避免過擬合
  3. 防止過擬合 (Overfitting)，提升模型的泛化能力
  4. 加速模型訓練過程
💡 透過限制模型的複雜度（懲罰大權重），強迫模型學習更簡單、更通用的規律，而不是死記硬背訓練數據。

  4. 在輸出層之後 (After Output Layer)
💡 BN 層對每一層的輸入進行標準化，解決了內部協變量偏移 (Internal Covariate Shift) 問題，讓每一層都能在穩定的分佈下學習。

  4. 訓練誤差高，測試誤差也高 (High Bias)
💡 模型太笨了，連訓練數據的規律都學不會，更別說舉一反三了。通常是因為模型複雜度不足或特徵不足。

  1. 減少環境中的隨機雜訊
  2. 加速模型的訓練速度
  3. 平衡當前即時獎勵與未來長期獎勵的重要性 (Future Reward Weighting)
  4. 增加代理行動的隨機性

#6412
  1. 狀態 s 的計算複雜度
  2. 狀態 s 發生的機率
  3. 當前獲得的即時獎勵 (Immediate Reward)
  4. 從狀態 s 開始的預期累積獎勵 (Expected Cumulative Reward)
💡 價值函數評估的是「長遠來看，處於這個狀態有多好」，而不僅僅是當下拿到的糖果。

貝爾曼方程式中的 max 操作意味著？
#6423
  1. 獎勵值是固定不變的
  2. 環境的反應是隨機不可預測的
  3. 代理總是選擇最差的行動以進行探索
  4. 代理假設自己會選擇能帶來最大價值的最佳行動 (Optimal Action)
💡 這是最佳化控制的基礎：當前狀態的價值，取決於我接下來能做的「最好」選擇。

如果折扣因子 γ = 0，代理會？
#6428
  1. 隨機採取行動，不考慮獎勵
  2. 變得極度短視，只在乎當下的即時獎勵 (Immediate Reward)
  3. 變得極度遠視，只在乎未來的獎勵
  4. 停止所有行動
💡 未來的價值都被乘上 0 了，所以代理只在乎 R(s, a)，完全不管後面的 V(s')。

  1. 錯誤的價值函數計算方式

  3. 任意策略下的價值函數
  4. 最佳策略 (Optimal Policy) 下的價值函數關係
💡 $V^*(s) = \max_a (R + \gamma \sum P V^*(s'))$，這是 RL 求解的終極目標。

Q-learning 是一種什麼類型的演算法？

  1. 基於值的 (Value-based) 演算法，學習動作價值函數 Q(s, a)
  2. 基於模型的 (Model-based) 演算法，學習環境模型
  3. 監督式學習 (Supervised Learning) 演算法
  4. 基於策略的 (Policy-based) 演算法
💡 Q-learning 不直接學策略，而是學每個動作「值多少分」(Q值)，然後選分最高的動作做。

  3. 卷積神經網路 (CNN) 用於提取特徵

  3. 只能處理離散動作空間 (Discrete Action Space)
  4. 計算邏輯最簡單且收斂最快

  3. 減少環境給予的獎勵數值
  4. 使用更深層的神經網路架構

情境：你訓練一個玩迷宮遊戲的 AI，但發現它一直在原地打轉，不肯去終點。檢查發現你設定每走一步扣 0.01 分（為了鼓勵走最短路徑），終點給 10 分。為什麼它會打轉？
#6441
  1. 迷宮設計太難，沒有解
  2. 可能是折扣因子 γ 太小，或探索率 ε 太低，導致 AI 變得短視
  3. AI 太笨，無法學會走迷宮
  4. 扣分太少，AI 不在乎
💡 這是常見的獎勵設計陷阱。如果遠處的大獎勵被 γ 折扣到微乎其微，代理就會為了避免眼前的微小懲罰而選擇消極策略。需要調整 γ 或獎勵結構。

情境：在訓練機械手臂抓取物體時，你發現模擬環境中訓練完美的模型，在真實世界完全無法工作。這叫什麼問題？該如何解決？
#6442
  1. 硬體故障或傳感器誤差
  2. 欠擬合 (Underfitting)
  3. Reality Gap (現實差距)。應使用域隨機化 (Domain Randomization) 技術
  4. 過擬合 (Overfitting)
💡 模擬永遠無法完美複製現實。透過在模擬中引入大量隨機擾動，讓模型「見多識廣」，它在面對真實世界的複雜性時就能視為另一種擾動而從容應對。

  4. 忘記加 Dropout 層
💡 沒有固定目標網路，DQN 的訓練就像「追著自己的尾巴跑」，目標值一直在變，導致震盪。經驗重播不足則會導致數據相關性過高。

機器學習治理與倫理

ML 中的公平性、當責性與透明度 (FAT)

FAT 原則中的 "F" 代表？
#6501
  1. Future (未來)：關注 AI 的未來發展
  2. Feature (特徵)：特徵工程的重要性
  3. Fast (快速)：模型推論速度要快
  4. Fairness (公平性)：確保模型對不同群體一視同仁，無歧視
💡 公平性確保 AI 不會因為性別、種族等敏感屬性而歧視特定群體。
chap-m4-ch5 sec-fat
選擇性偏見 (Selection Bias) 發生在？
#6505
  1. 模型架構設計太過簡單
  2. 測量工具本身不準確
  3. 訓練數據無法代表真實世界的母體 (Sampling Bias)
  4. 歷史數據本身反映了社會偏見
💡 例如只用大學生的照片訓練人臉識別，結果模型認不出老年人。
chap-m4-ch5 sec-fat
當責性 (Accountability) 強調？
#6508
  1. 模型必須達到 100% 的準確率
  2. 必須有明確的責任歸屬機制 (Responsibility)，當 AI 出錯時有人負責
  3. 模型的原始碼必須完全開源
  4. 訓練數據必須免費公開
💡 當自駕車撞人，是車廠、軟體商還是駕駛的錯？當責性要求在 AI 系統設計之初就釐清這些問題。
chap-m4-ch5 sec-fat
歷史偏見 (Historical Bias) 源於？
#6511
  1. 測量儀器的故障或誤差
  2. 演算法本身的設計錯誤
  3. 數據反映了現實世界中既有的社會偏見或不公 (Existing Social Bias)
  4. 數據採樣過程中的隨機誤差
💡 如果歷史數據顯示「CEO 多為男性」，模型可能會學到「男性更適合當 CEO」的偏見，這就是歷史偏見的複製。
chap-m4-ch5 sec-fat
透明度 (Transparency) 要求？
#6514
  1. 公開所有的原始程式碼
  2. 模型架構必須非常簡單
  3. 模型的決策過程應該是可理解、可解釋且可追溯的 (Explainable and Traceable)
  4. 所有的訓練數據必須公開
💡 黑盒子模型（如深度學習）雖然準，但若無法解釋，在醫療、金融等高風險領域難以被信任。
chap-m4-ch5 sec-fat
測量偏見 (Measurement Bias) 發生在？
#6517
  1. 訓練樣本數量太少
  2. 特徵或標籤的測量方式有誤或存在系統性誤差 (Systematic Error)
  3. 歷史數據本身存在不公
  4. 演算法設計太過複雜
💡 例如用「逮捕率」作為「犯罪率」的代理變數。因為某些區域警察巡邏多，逮捕率自然高，這不代表該區人更愛犯罪，這就是測量偏見。
chap-m4-ch5 sec-fat
演算法歧視 (Algorithmic Discrimination) 通常是由什麼引起的？
#6521
  1. 硬體設備發生故障
  2. 訓練數據中的偏見被模型學習並放大 (Bias Amplification)
  3. 電腦程式具有惡意意圖
  4. 網路傳輸延遲導致數據錯誤
💡 AI 是一面鏡子，反映了數據中的偏見。如果數據有毒，模型就有毒。
chap-m4-ch5 sec-fat
代理變數 (Proxy Variable) 在公平性問題中是指？
#6525
  1. 隨機生成的變數
  2. 表面上看似中立，但實際上與敏感屬性高度相關的變數 (Correlated Variable)
  3. 模型的預測目標變數
  4. 網路代理伺服器 (Proxy Server)
💡 即使刪除了「種族」欄位，模型仍可能透過「郵遞區號」（因為種族居住隔離）學會歧視。這就是代理變數的陷阱。
chap-m4-ch5 sec-fat
為了減少偏見，在數據收集階段應該？
#6528
  1. 刪除所有敏感屬性的數據
  2. 只收集最方便取得的數據
  3. 確保數據的多樣性與代表性 (Diversity and Representation)，覆蓋各個群體
  4. 停止收集任何數據
💡 源頭管理最重要。如果數據本身就是偏頗的，後續再怎麼調模型都事倍功半。
chap-m4-ch5 sec-fat
隱私保護與模型公平性之間？
#6531
  1. 兩者是一樣的概念
  2. 可能存在衝突 (Trade-off)，因為檢測公平性需要敏感數據
  3. 兩者完全無關
  4. 總是互相促進，沒有衝突

  3. 傳統統計學 (Statistics)
  4. 深度學習 (Deep Learning)

  4. 只能解釋線性回歸模型

  3. 模型整體的運作邏輯
  4. 模型對單個特定樣本的預測原因 (Individual Prediction Explanation)

  4. 提升了預測值 (正向貢獻)，使結果高於平均值

  4. 訓練一個更複雜的深度學習模型

數據漂移 (Data Drift) 是指？
#6504
  1. 程式碼邏輯發生改變
  2. 伺服器硬體發生故障
  3. 輸入數據的統計分佈隨時間發生變化 (Distribution Shift)
  4. 模型內部的權重參數發生改變
💡 例如訓練時用戶平均 20 歲，上線後變成 50 歲，這就是數據漂移，可能導致模型失效。

PSI (Population Stability Index) 用於衡量？
#6507
  1. 模型的記憶體使用量
  2. 模型的推論計算速度
  3. 模型的預測準確率 (Accuracy)
  4. 兩個數據分佈之間的差異穩定性 (Population Stability)，用於檢測漂移
💡 PSI < 0.1 通常表示分佈穩定；PSI > 0.25 表示分佈發生顯著變化（漂移），需要警惕。

概念漂移 (Concept Drift) 是指？
#6510
  1. 訓練數據出現大量缺失值
  2. 輸入特徵與目標變數之間的映射關係發生變化 (Relationship Change)
  3. 輸入數據的統計分佈發生改變
  4. 模型發生過擬合現象
💡 例如「垃圾郵件」的定義變了，或者消費者對商品的喜好變了。即使輸入特徵沒變，舊的預測邏輯也失效了。

#6515
  1. 增加伺服器的硬體資源
  2. 立即停止模型服務
  3. 使用新數據重新訓練模型 (Retraining) 以適應新的分佈
  4. 修改模型的程式碼邏輯
💡 當世界變了，模型也要跟著變。定期或觸發式地用新數據更新模型，是維持效能的關鍵。
chap-m4-ch5 sec-model-governance

#6519
  1. 只包含模型部署階段的管理
  2. 只包含數據清洗與預處理階段
  3. 只包含模型訓練階段的管理
  4. 涵蓋模型全生命週期的管理 (Full Lifecycle Management)，包括開發、部署、監控與退役
💡 治理不是一次性的活動，而是一套完整的流程，確保模型在任何時候都是合規、有效且可控的。

  3. 及時發現模型性能衰退 (Model Decay) 或漂移
  4. 為了在儀表板上展示漂亮的圖表
💡 模型像汽車一樣會折舊。定期健檢（監控指標）才能知道何時該進廠維修（重新訓練）。

深度思考情境題

情境：你的銀行信用評分模型被投訴對女性申請者不公。你檢查了特徵，發現已經刪除了「性別」欄位。這時你應該懷疑什麼？如何驗證？
#6541
  1. 訓練數據量太少，導致模型不穩定
  2. 存在代理變數 (Proxy Variables)。應檢查其他特徵是否與性別高度相關
  3. 投訴者在說謊，模型不可能出錯
  4. 模型產生了自我意識，故意歧視
💡 這是最常見的隱形歧視。即使不給性別，模型也能從「購買化妝品頻率」猜出性別。必須進行相關性分析和公平性指標檢測。

情境：你使用深度學習模型預測房價，準確率很高，但客戶要求解釋為什麼他的房子被估這麼低。你應該使用什麼工具？
#6542
  1. 畫出複雜的神經網路架構圖給他看
  2. 重新訓練一個簡單的線性模型來解釋
  3. 告訴他這是 AI 的決定，屬於商業機密無法解釋
  4. 使用 SHAP 或 LIME 進行局部解釋 (Local Explanation)，指出具體是哪些特徵拉低了預測值
💡 客戶不關心神經網路有幾層，他只關心「為什麼」。SHAP/LIME 能給出「屋齡 -50 萬」、「捷運 +20 萬」這種人類聽得懂的理由。

情境：你的模型上線一個月後，準確率從 90% 掉到 70%。檢查發現輸入數據的分佈與訓練時有很大差異。這是什麼現象？應如何處理？

情境：選擇性偏見 (Selection Bias) 是指？
#6547
  1. 訓練數據不能代表真實世界的母體 (Sampling Bias)
  2. 特徵選擇過程出現錯誤
  3. 演算法本身存在偏見
  4. 模型選擇了錯誤的演算法
💡 例如用白人數據訓練人臉辨識，導致對黑人辨識率低。

  2. 模型的決策過程應該是可見、可理解且可解釋的 (Explainable Decision Process)

  4. 伺服器硬體架構必須透明
