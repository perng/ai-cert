進階分析方法

進階分析方法 (Advanced Analytics Methods) 幫助我們從數據中挖掘更深層次的價值。

時間序列分析

時間序列分析 (Time-series Analysis) 用於分析隨時間變化的數據，如股票價格、氣溫、銷售額。

  • 平穩性 (Stationarity)：數據的統計特性（平均值、變異數）不隨時間變化。
    • 檢定方法：Augmented Dickey-Fuller (ADF) 檢定。若 p-value < 0.05，則拒絕非平穩假設（即數據是平穩的）。
  • 季節性 (Seasonality)：數據呈現週期性的變化模式。
  • 分解 (Decomposition)：將時間序列分解為趨勢 (Trend)、季節性 (Seasonality) 和殘差 (Residual)。

ARIMA

ARIMA (AutoRegressive Integrated Moving Average) 是經典的時間序列預測方法，包含三個部分 (p, d, q)： 1. AR (AutoRegressive, p)：自迴歸。當前值與過去 p 個值的線性組合有關。 \[ Y_t = c + \phi_1 Y_{t-1} + \dots + \phi_p Y_{t-p} + \epsilon_t \] 2. I (Integrated, d)：差分。將非平穩數據轉換為平穩數據所需的差分次數 d。 3. MA (Moving Average, q)：移動平均。當前值與過去 q 個預測誤差的線性組合有關。 \[ Y_t = \mu + \epsilon_t + \theta_1 \epsilon_{t-1} + \dots + \theta_q \epsilon_{t-q} \]

參數選擇：

  • ACF (Autocorrelation Function)：決定 MA 的階數 q。
  • PACF (Partial Autocorrelation Function)：決定 AR 的階數 p。

Prophet

Prophet 是由 Facebook 開發的時間序列預測工具，特別擅長處理具有強烈季節性和假期效應的數據。它基於加法模型： \[ y(t) = g(t) + s(t) + h(t) + \epsilon_t \] 其中 g(t) 是趨勢，s(t) 是季節性，h(t) 是假期效應。

  • 優點：
    • 自動處理缺失值和異常值。
    • 可以加入自定義假期 (Holidays) 和事件。
    • 允許趨勢變點 (Changepoints) 的自動檢測。

Python 範例：使用 Prophet 預測

from prophet import Prophet
import pandas as pd
import numpy as np

# 準備數據 (Prophet 要求列名為 ds 和 y)
# 創建一個更有趨勢和季節性的數據，避免優化失敗
dates = pd.date_range(start='2023-01-01', periods=100)
y = np.linspace(0, 10, 100) + np.sin(np.linspace(0, 10, 100)) + np.random.normal(0, 0.1, 100)

df = pd.DataFrame({
    'ds': dates,
    'y': y
})

# 訓練模型
m = Prophet()
m.add_country_holidays(country_name='TW') # 加入台灣假期
m.fit(df)

# 建立未來 dataframe
future = m.make_future_dataframe(periods=30)
forecast = m.predict(future)

# 繪圖
fig1 = m.plot(forecast)

網路分析與圖演算法

網路分析與圖演算法 (Network Analysis and Graph Algorithms) 用於研究實體之間的關係。

中心性指標

  • 度中心性 (Degree Centrality)：節點的連接數。衡量節點的活躍度。
  • 中介中心性 (Betweenness Centrality)：節點位於其他節點對之間最短路徑上的次數。衡量節點作為「橋樑」的重要性。
  • 接近中心性 (Closeness Centrality)：節點到所有其他節點的最短路徑長度總和的倒數。衡量節點傳播訊息的速度。
  • PageRank：Google 搜尋引擎的核心演算法。一個網頁的重要性取決於指向它的網頁的重要性。 \[ PR(u) = \sum_{v \in B_u} \frac{PR(v)}{L(v)} \]

社群偵測 (Community Detection)

用於發現網路中緊密連接的節點群體。

  • Louvain 演算法：基於模組度 (Modularity) 最佳化的快速演算法。
  • Girvan-Newman 演算法：基於邊介數 (Edge Betweenness) 的分裂演算法。

Python 範例：使用 NetworkX 計算中心性

import networkx as nx

G = nx.karate_club_graph()

# 計算 Degree Centrality
degree_cent = nx.degree_centrality(G)
print("Top 5 nodes by degree:", sorted(degree_cent.items(), key=lambda x: x[1], reverse=True)[:5])

地理空間資料分析

地理空間資料分析 (Geospatial Data Analysis) 處理帶有地理位置信息的數據，常用工具包括 GeoPandas。

  • CRS (Coordinate Reference Systems)：座標參考系統。
    • EPSG:4326 (WGS84)：經緯度，GPS 常用。
    • EPSG:3857 (Web Mercator)：投影座標，Google Maps 常用。
  • 空間操作：
    • Buffer：建立緩衝區（例如：距離商店 500 公尺內的區域）。
    • Intersection：計算兩個幾何圖形的交集。 ## 統計檢定與推論 (Statistical Hypothesis Testing) {#sec-statistical-tests}

t 檢定 (t-test)

t 檢定是一種常用的統計假設檢定方法，用於比較兩個平均值（Means）是否存在顯著差異。它適用於樣本數較小且母體標準差未知的情況（假設母體為常態分佈）。

  • 單樣本 t 檢定 (One-sample t-test)：
    • 比較一個樣本的平均值與已知的母體平均值（或特定值）。
    • 例子：檢驗某班級的平均成績是否顯著高於全校平均成績 70 分。
  • 獨立樣本 t 檢定 (Independent two-sample t-test)：
    • 比較兩個獨立樣本的平均值。
    • 例子：檢驗服用新藥的組別與服用安慰劑的組別，其康復時間是否有顯著差異。
  • 成對樣本 t 檢定 (Paired samples t-test)：
    • 比較同一組樣本在不同時間點（或不同條件下）的平均值。
    • 例子：檢驗同一組學生在參加補習班前後的成績是否有顯著進步。

變異數分析 (ANOVA)

當需要比較三組或以上獨立樣本的平均值是否有顯著差異時，應使用變異數分析 (Analysis of Variance, ANOVA)。

  • 單因子變異數分析 (One-way ANOVA)：
    • 用途：檢驗一個自變數（因子）的不同水準對應變數平均值是否有顯著影響。
    • 假設：各組樣本呈常態分佈、變異數相等（齊一性）、樣本獨立。
    • 例子：比較三種不同教學方法（A、B、C）對學生成績是否有顯著差異。

Python 範例：One-way ANOVA

from scipy import stats

# 三組學生成績
method_A = [82, 85, 88, 90, 86]
method_B = [75, 78, 80, 79, 77]
method_C = [92, 95, 94, 96, 93]

# F-oneway ANOVA
f_stat, p_val = stats.f_oneway(method_A, method_B, method_C)
print(f"F-statistic: {f_stat:.2f}, p-value: {p_val:.4f}")
F-statistic: 63.94, p-value: 0.0000

卡方檢定 (Chi-square Test)

卡方檢定主要用於分析類別資料 (Categorical Data)。

  • 獨立性檢定 (Test of Independence)：
    • 用途：檢驗兩個類別變數之間是否獨立（即是否有關聯）。
    • 例子：檢驗「性別」與「購買意願」（買/不買）是否有關聯。
  • 適合度檢定 (Goodness of Fit Test)：
    • 用途：檢驗一個類別變數的觀察分佈是否符合預期分佈。
    • 例子：檢驗擲骰子 600 次，各點數出現次數是否均勻（各 100 次）。

Python 範例：卡方獨立性檢定

from scipy import stats
import numpy as np

# 建立列聯表 (Contingency Table)
# 例如：性別 (男, 女) x 購買意願 (買, 不買)
#        買   不買
#  男    30    20
#  女    40    10
observed = np.array([[30, 20], [40, 10]])

# 卡方檢定
chi2, p, dof, expected = stats.chi2_contingency(observed)
print(f"Chi2 statistic: {chi2:.2f}, p-value: {p:.4f}")
Chi2 statistic: 3.86, p-value: 0.0495

比例檢定 (Proportion Test)

用於檢驗比例（如成功率、支持率）是否符合預期或兩組比例是否有差異。

  • 單樣本比例檢定 (One-sample proportion test)：
    • 檢驗樣本比例是否顯著異於某個特定值（如 0.5）。
    • 例子：檢驗某候選人的支持率是否顯著超過 50%。
  • 雙樣本比例檢定 (Two-sample proportion test)：
    • 檢驗兩個獨立樣本的比例是否有顯著差異。
    • 例子：檢驗 A 網頁與 B 網頁的轉換率（Conversion Rate）是否有顯著差異。

Python 範例：雙樣本比例檢定

from statsmodels.stats.proportion import proportions_ztest
import numpy as np

# 樣本數據：[成功次數 A, 成功次數 B]
count = np.array([30, 45])
# 樣本總數：[總數 A, 總數 B]
nobs = np.array([100, 100])

# 檢定兩組比例是否不同
stat, pval = proportions_ztest(count, nobs)
print(f"Z-statistic: {stat:.2f}, p-value: {pval:.4f}")
Z-statistic: -2.19, p-value: 0.0285

Python 範例：單樣本 t 檢定

from scipy import stats

# 假設我們有一組學生成績，想檢驗平均分是否顯著異於 70 分
scores = [72, 75, 68, 70, 74, 78, 71, 73, 69, 76]

# H0: mu = 70
# H1: mu != 70
t_stat, p_val = stats.ttest_1samp(scores, 70)

print(f"T-statistic: {t_stat:.2f}, p-value: {p_val:.4f}")

if p_val < 0.05:
    print("拒絕虛無假設，平均分顯著異於 70")
else:
    print("無法拒絕虛無假設")
T-statistic: 2.57, p-value: 0.0304
拒絕虛無假設，平均分顯著異於 70

相關性檢定 (Correlation Test)

相關性檢定用於評估兩個變數之間的關聯強度和方向。

  • 皮爾森相關檢定 (Pearson correlation test)：
    • 適用條件：兩個變數皆為連續變數，且呈常態分佈，存在線性關係。
    • 指標：皮爾森相關係數 (r)，範圍從 -1 到 1。
      • r=1：完全正相關。
      • r=-1：完全負相關。
      • r=0：無線性相關。
  • 斯皮爾曼等級相關檢定 (Spearman rank correlation test)：
    • 適用條件：變數不符合常態分佈，或變數為順序尺度 (Ordinal)。它基於變數的等級 (Rank) 而非原始數值。
    • 指標：斯皮爾曼等級相關係數 𝞺。

Python 範例：計算相關係數

from scipy import stats
import numpy as np

# 產生線性相關的數據
x = np.linspace(0, 10, 20)
y = 2 * x + np.random.normal(0, 2, 20) # y = 2x + noise

# 皮爾森相關
r, p_pearson = stats.pearsonr(x, y)
print(f"Pearson r: {r:.2f}, p-value: {p_pearson:.4f}")

# 產生非線性單調相關的數據 (例如指數關係)
y_exp = np.exp(x/3)

# 斯皮爾曼相關
rho, p_spearman = stats.spearmanr(x, y_exp)
print(f"Spearman rho: {rho:.2f}, p-value: {p_spearman:.4f}")
Pearson r: 0.97, p-value: 0.0000
Spearman rho: 1.00, p-value: 0.0000

非參數檢定 (Non-parametric Tests)

當數據不符合常態分佈假設，或數據為順序尺度時，應使用非參數檢定。

  • Mann-Whitney U 檢定：
    • 用途：比較兩組獨立樣本的中位數是否有顯著差異（對應獨立樣本 t 檢定）。
    • 適用：數據非常態分佈，或樣本數較小。
  • Kruskal-Wallis 檢定：
    • 用途：比較三組或以上獨立樣本的分佈位置（中位數）是否有顯著差異（對應 One-way ANOVA）。
    • 適用：多組數據非常態分佈。

Python 範例：非參數檢定

from scipy import stats

# 兩組非常態分佈數據
group1 = [10, 12, 15, 18, 20]
group2 = [25, 28, 30, 32, 35]

# Mann-Whitney U test
u_stat, p_u = stats.mannwhitneyu(group1, group2)
print(f"Mann-Whitney U p-value: {p_u:.4f}")

# 三組數據
group3 = [15, 18, 22, 25, 28]

# Kruskal-Wallis test
h_stat, p_h = stats.kruskal(group1, group2, group3)
print(f"Kruskal-Wallis p-value: {p_h:.4f}")
Mann-Whitney U p-value: 0.0079
Kruskal-Wallis p-value: 0.0074

型一錯誤與型二錯誤

在假設檢定中，我們可能會犯兩種錯誤：

  • 型一錯誤 (Type I Error, 𝝰)：偽陽性 (False Positive)。
    • 定義：當虛無假設 H0 為真時，我們卻拒絕了它。
    • 機率：顯著水準 𝝰 (通常為 0.05)。
    • 例子：法庭判決無罪的人有罪（冤獄）；沒病的人被診斷為有病。
  • 型二錯誤 (Type II Error, 𝝱)：偽陰性 (False Negative)。
    • 定義：當虛無假設 H0 為假（即對立假設 H1 為真）時，我們卻沒有拒絕 H0。
    • 機率：𝝱。
    • 例子：法庭判決有罪的人無罪（縱放）；有病的人被診斷為沒病。

檢定力 (Statistical Power)： * 定義：正確拒絕錯誤的 H0 的機率，即 1 - 𝜷。 * 目標：在固定 𝝰 的情況下，盡量提高檢定力（例如增加樣本數）。
