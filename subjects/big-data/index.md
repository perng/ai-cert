# 前言 {.unnumbered}

本學科「大數據處理、分析與應用」涵蓋了從基礎統計學、資料前處理、特徵工程，到進階的機器學習演算法、大數據系統架構以及資料隱私與倫理等廣泛議題。

本書旨在協助讀者掌握處理大規模數據所需的關鍵技能，並通過實務案例與試題解析，深入理解各項技術的應用場景。

## 學習目標

1.  **統計與機率基礎**：理解描述性統計、機率分佈（如常態分佈、卜瓦松分佈）及假設檢定。
2.  **資料前處理與清洗**：掌握缺失值處理、異常值偵測、標準化與正規化等技術。
3.  **特徵工程**：學習如何從原始數據中提取有價值的特徵，包括編碼技術與降維方法（如 PCA）。
4.  **資料視覺化**：運用圖表（如箱型圖、熱力圖）有效地傳達數據洞察。
5.  **機器學習與演算法**：熟悉分類、分群（如 K-means, DBSCAN）及關聯規則學習等分析方法。
6.  **大數據技術架構**：了解分散式資料庫、流式處理及雲端運算架構。
7.  **資料治理與倫理**：認識資料隱私保護技術（如去識別化、同態加密）及相關法規。
