# 前言 {.unnumbered}

歡迎來到《生成式 AI 應用與規劃》備考指南。本書旨在協助讀者準備 iPAS 初級 AI 應用規劃師能力鑑定的第二科考試。

## 考試大綱與知識體系

本書內容基於歷屆試題與最新技術趨勢歸納，涵蓋以下核心領域：

1.  **生成式 AI 模型架構與機制**：深入理解 Transformer、Diffusion 等核心技術。
2.  **進階提示工程**：掌握 CoT、ToT 等高階推理策略。
3.  **進階 RAG 與系統架構**：探討 RAG、Fine-tuning 與 MCP 等架構選擇。
4.  **AI 代理人 (Agentic AI)**：從單一模型走向自主代理與多代理系統。
5.  **No Code / Low Code 開發**：利用現代工具加速 AI 應用開發。
6.  **專案管理與評估**：從 POC 到部署的完整流程與效能指標。
7.  **資安、合規與倫理**：應對 Prompt Injection、隱私洩漏等新興威脅。

希望本書能成為您通往 AI 應用規劃師之路的有力助手。
